# @praxy/codegen

Typed row interfaces + `Col<T>` column-key constants generated from a project's **live schema**,
invoked on demand — mirrors `praxy_codegen`'s scope (widened slightly: row interfaces too, not just
column constants). Deliberately **not** a bundler plugin or a file watcher: generated files that show
up in diffs beat a codegen step that runs silently on every save. Talks to the data-plane schema API
(`/v1/databases`) directly with `fetch` — API-key only, same boundary `DatabaseEndpoints.cs` draws.

## Install

Workspace-internal only — not published to npm. From `sdk/js/`: `npm install`.

## Usage

```bash
npx praxy-codegen \
  --endpoint http://localhost:5090 --project <project-id> --api-key <key> \
  --database main --table todos --output src/db/todos.ts
```

`--api-key` falls back to the `PRAXY_API_KEY` environment variable so it never sits in shell history.
`--database`/`--table` are the resource **keys**, not wire ids. `--class-name` overrides the default
PascalCase-of-the-table-key name for the generated interface/constants.

Output (`src/db/todos.ts`):

```ts
// GENERATED by @praxy/codegen — do not edit by hand.
// Regenerate with: npx praxy-codegen --endpoint ... --database main --table todos --output ...

import { Col } from "@praxy/core";

export interface Todos {
  title: string;
  done?: boolean;
}

export const TodosColumns = {
  id: new Col<string>("$id"),
  tableId: new Col<string>("$tableId"),
  databaseId: new Col<string>("$databaseId"),
  createdAt: new Col<string>("$createdAt"),
  updatedAt: new Col<string>("$updatedAt"),
  title: new Col<string>("title"),
  done: new Col<boolean>("done"),
};
```

Pair the interface with `tableRef<Todos>(databaseId, tableId)` (ids, not keys — construct this by
hand with environment-configured ids, the same pattern `sdk/flutter/example/lib/db.dart` uses) and the
column constants with `Query` — `Query.equal(TodosColumns.title, "Buy milk")`.

## Development

From `sdk/js/`:

```bash
npm run test -w packages/codegen        # vitest — a fake `fetch`, no server needed
npm run typecheck -w packages/codegen   # tsc --noEmit
npm run build -w packages/codegen       # tsc -p tsconfig.build.json → dist/ (bin: praxy-codegen)
```
