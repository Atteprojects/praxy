# praxy_codegen

On-demand codegen for the [Praxy](https://github.com/<your-fork-or-org>/praxy) Flutter SDK: emits
typed `Col<T>` column constants for one table into a committed Dart file, by reading the table's
live schema from a running Praxy instance. **Not a `build_runner` builder** — run it by hand
whenever a table's columns change; the output is a plain file you commit, not something regenerated
on every build.

`Col<T>`/`TableRef<T>`/`RowCodec<T>` (from
[`praxy_core`](https://github.com/<your-fork-or-org>/praxy/tree/main/sdk/flutter/praxy_core)) work
identically whether the `Col`s come from this tool or you write them by hand — this package is
purely a convenience for not hand-typing every column name and type.

## Install

Not published to pub.dev yet:

```yaml
dev_dependencies:
  praxy_codegen:
    git:
      url: https://github.com/<your-fork-or-org>/praxy
      path: sdk/flutter/praxy_codegen
```

## Usage

Create the database/table via the Praxy console first (this tool reads an existing schema, it
doesn't create one), then:

```bash
dart run praxy_codegen \
  --endpoint http://localhost:5090 --project <projectId> \
  --api-key <key> --database main --table todos \
  --output lib/db/todos_columns.dart
```

| Flag | Required | Notes |
|---|---|---|
| `--endpoint` | yes | Praxy API base URL. |
| `--project` | yes | Project id (`X-Praxy-Project`). |
| `--api-key` | yes* | Needs the `databases.read` scope. *Falls back to the `PRAXY_API_KEY` env var, so it never has to sit in shell history. |
| `--database` | yes | Database key. |
| `--table` | yes | Table key. |
| `--output` | yes | Output `.dart` file path. |
| `--class-name` | no | Override the generated class name (defaults from the table key). |

Produces a file like:

```dart
// GENERATED BY praxy_codegen — do not hand-edit.
// Table: todos (database: main)
// Regenerate: dart run praxy_codegen --database main --table todos ...

import 'package:praxy_core/praxy_core.dart';

abstract final class Todos {
  static const id = Col<String>(r'$id');
  static const createdAt = Col<DateTime>(r'$createdAt');
  static const updatedAt = Col<DateTime>(r'$updatedAt');
  static const title = Col<String>('title');
  static const done = Col<bool>('done');
}
```

...usable directly in query builders: `Query.equal(Todos.done, false)`.

## Development

From the workspace root (`sdk/flutter/`): `dart pub get`, then `dart test praxy_codegen`.
